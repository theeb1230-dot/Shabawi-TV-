# Shabawi TV

Integration workspace for reviewing and consolidating reusable components from the public Ahmd3301 repositories.

Start with [inventory/AHMD3301_REPOSITORIES.md](inventory/AHMD3301_REPOSITORIES.md).

## Safety
Original upstream repositories are not modified. Secrets, credentials, private tokens, signing material, and external database contents are not imported. Each imported component must retain its source repository and exact upstream SHA.
